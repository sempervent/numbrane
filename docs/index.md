# NUMBRANE documentation

**NUMBRANE** — *Numerical Unified Multilingual Bridge for Reproducible Algorithmic Nonlinear Expression*

A polyglot system for generative audiovisual art created entirely from mathematics, algorithms, simulation, procedural rules, and human interaction.

**Not** generative AI. No LLM, diffusion, or inference APIs in the runtime.
