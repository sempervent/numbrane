# circle-lattice parameters

| Path | Type | Default | Meaning |
|------|------|---------|---------|
| `geom.radius` | number | `1.0` | Circle radius in cartesian-2d |
| `geom.rings` | integer ≥ 0 | `1` | Hex rings around center (`0` = center only) |
| `geom.rotation_deg` | number | `0` | Rotation of lattice in degrees |
| `seed` (recipe) | u32 | required | Accepted for protocol discipline; unused by default geometry |
